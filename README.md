# Resource Reflector

A small frontend tool for storing, organizing, and revisiting personal resources.

The application allows you to collect:
1. Links
2. Notes
3. Files (images, PDFs, documents)

Each resource can be tagged and later searched for quick reflection and reuse.

All data is stored locally using the browser’s storage.  
No accounts, no servers, no tracking.

Everything stays on your device.

## Stack
- HTML
- CSS
- JavaScript
- LocalStorage (no backend)

## Usage
1. Open `index.html` in a modern browser.
2. Add a resource by choosing its type (link, note, or file).
3. Use tags and search to organize and retrieve resources.

## Notes
- Images are previewed directly in the app.
- Other files are stored as downloadable items.
- Storage is limited by browser LocalStorage size (~5MB).
