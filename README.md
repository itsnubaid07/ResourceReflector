# Resource Reflector

A small local-first browser app for storing, organizing, and revisiting personal resources.

The application allows you to collect:

1. Links  
2. Notes  
3. Files (images, PDFs, documents)

Each resource can be tagged and searched for quick reflection and reuse.

All data is stored locally using IndexedDB.  
No accounts, no servers, no tracking.

Everything stays on your device.

## Stack

- HTML5
- CSS3
- JavaScript (ES6+)
- IndexedDB

## Features

- Local-first storage
- Link, note, and file support
- Tag-based organization
- Live search and filtering
- Image preview support
- Offline-friendly architecture

## Usage

1. Open `index.html` in a modern browser.
2. Add a resource by choosing its type.
3. Use tags and search to organize and retrieve resources.

## Notes

- Images are previewed directly in the app.
- Other files are stored as downloadable items.
- Storage capacity depends on the browser and device.
